# Java Full Stack Modules (JFS)

This repository contains the practical projects for Module 1, Module 2, and Module 3.

## Structure

```
.
├── Module - 1/
│   └── Inventory Management System/
├── Module - 2/
│   └── MultiThreadedFileProcessor/
└── Module - 3/
    └── employee-management-web/
```

### Module 1: Inventory Management System
- Core Java implementation featuring inventory tracking, file handling, and category management.

### Module 2: Multi-Threaded File Processor
- Multithreaded Java project demonstrating concurrent data processing, synchronization, and automated batch reporting.

### Module 3: Employee Management Web Application
- Spring Boot web application configured with Maven (`mvnw`), REST APIs, and employee data management.
